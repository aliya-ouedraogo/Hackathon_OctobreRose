# EchoBreast

Prototype d'outil d'aide à l'analyse des échographies mammaires, développé par l'équipe BLOSSOM
pour le hackathon « Technologies et IA contre le cancer du sein » (Octobre Rose).

EchoBreast apporte un regard complémentaire au professionnel de santé : probabilités normale /
bénigne / maligne, contour de la zone repérée, zones qui ont pesé dans le calcul et explication écrite.

**Ce n'est pas un diagnostic.** Seul un prélèvement confirme ou écarte un cancer. Prototype non validé
cliniquement, entraîné sur le jeu public BUSI (Égypte).

**Version de démonstration :** utilisez les cas de démonstration ou des images anonymisées.
N'importez aucune image permettant d'identifier une patiente.
